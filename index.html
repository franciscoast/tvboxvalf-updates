Launcher Valf · Instaladores

Tocá cada app para descargarla. Cuando termine, tocá Instalar. Hacelas en este orden.

1 Tailscale Para la conexión a distancia 2 Termux Para abrir la puerta de instalación 3 Termux:Boot Para que la puerta quede automática (abrila una vez después de instalar)

✓ Si al instalar pide permitir "Fuentes desconocidas", activá Downloader y volvé atrás.
